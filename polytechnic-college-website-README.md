# Government Polytechnic Colleges Website

A static informational website that presents information about Government Polytechnic Colleges in Rajasthan. It includes a landing page, college/location-specific pages, images, styling, and a contact page.

## Tech Stack

- HTML5
- CSS3
- Local image assets

## Features Present in the Source

- Landing page introducing Government Polytechnic Colleges in Rajasthan
- Separate pages for multiple locations/colleges
- College-related images and logos
- Contact page
- Local CSS stylesheets and supporting informational PDF documents

## Getting Started

No build tools are required for the static website.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/polytechnic-college-website.git
cd polytechnic-college-website
```

### 2. Open the website

Open `index.html` in a web browser.

For a local development server, if Python is installed, run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
